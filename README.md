# MIDDLE EAST

Website of MIDDLE EAST — a borderless rock band rooted in the Eastern Mediterranean.
*Playing everywhere. Belonging nowhere.*

Static site (HTML, CSS, vanilla JS), no build step. Open `index.html` or serve the folder with any static server.

- `index.html`, `styles.css`, `app.js` — the site
- `img/` — photos (`img/full/` holds the full-size versions shown in the photo viewer)
- `fonts/` — self-hosted webfonts (Saira as a stand-in for Eurostile, MonteCarlo, Annie Use Your Telescope, LINE Seed JP)

Design: Kirill Blik.
